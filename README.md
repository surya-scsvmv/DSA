## Getting started

### Prerequisite

Install a C compiler such as [GCC](https://gcc.gnu.org/) or use a C development environment available on your system.

### Compile and run

From the directory containing the desired source file:

```bash
gcc program.c -o program
```

Run on Linux/macOS:

```bash
./program
```

On Windows, run the generated executable:

```powershell
.\program.exe
```

Replace `program.c` with the actual source filename. Follow the prompts printed by each program; input requirements vary by exercise.

## Learning goals

- Understand operations and trade-offs of common data structures.
- Practise implementing algorithms in C.
- Trace program flow and test different inputs.
- Keep lab work organized for revision and study.
